Atividade avaliativa pratica

Ficha do Aluno Completa

Revisao dos formularios: tipos de input, validacao, radio, select, checkbox e organizacao visual.

Missao

Criar uma pagina chamada ficha-aluno.html com um formulario completo para cadastro simples de aluno.

<form>
  Nome completo
  Idade
  E-mail
  Senha
  Serie (radio)
  Cidade (select)
  Interesses (checkbox)
  Botao Enviar
</form>

Checklist obrigatorio

☐ Usar <form>, <label> e <input> corretamente.
☐ Usar os tipos text, number, email e password.
☐ Usar required e placeholder em campos importantes.
☐ Incluir radio, select/option e checkbox.
☐ Aplicar CSS leve: fonte, espacamento, borda, fundo e card.
☐ Testar se o arquivo abre no navegador e se os campos aparecem organizados.

Criterios de avaliacao

2 pts
Estrutura HTML
2 pts
Tipos de campos
2 pts
Campos de escolha
2 pts
CSS e organizacao
2 pts
Entrega e explicacao

Resumo para o caderno

Formulario completo junta campos de texto, numero, e-mail, senha, escolhas e botao. O CSS ajuda a organizar para o usuario preencher com facilidade.
