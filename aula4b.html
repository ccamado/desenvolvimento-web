Lab 1: Estilizando Fonte e Fundo

Vamos ao computador! Siga cada passo com calma. Não pule etapas — cada uma depende da anterior.

🌐

Plataforma: CodePen — Zero login, zero instalação!

O CodePen é um editor online onde você escreve HTML e CSS e vê o resultado em tempo real. É gratuito e não precisa criar conta para usar.

▶ Abrir o CodePen agora   ← Clique aqui e depois volte para seguir os passos

🗺️ O que faremos hoje

Em 6 passos, vamos partir de um formulário sem estilo e adicionar fonte bonita, cor de fundo agradável e espaçamento básico. Resultado esperado ao final:

codepen.io

📝 Ficha do Aluno

📋 Passos do Laboratório

PASSO 1 — Estrutura base

Cole o HTML inicial no CodePen

No CodePen, você verá 3 caixas: HTML, CSS e JS. Clique na caixa HTML e cole o código abaixo:

<h2>Ficha do Aluno</h2>

<form>

  <label>Nome:</label>
  <br>
  <input type="text" placeholder="Seu nome">
  <br><br>

  <label>Turma:</label>
  <br>
  <input type="text" placeholder="Ex: 2A">
  <br><br>

  <label>E-mail:</label>
  <br>
  <input type="email" placeholder="voce@email.com">
  <br><br>

  <button type="submit">Enviar</button>

</form>
✅Você deve ver o formulário sem estilo no painel de preview à direita. Feio, mas funcionando!
PASSO 2 — Mudar a fonte do body

Aplicar uma fonte moderna

Clique na caixa CSS e cole o código abaixo. Isso muda a fonte de toda a página.

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
}
👀Notou a diferença? A letra ficou mais limpa e uniforme! O seletor body afeta todos os elementos da página.
PASSO 3 — Cor de fundo

Mudar o fundo da página

Ainda no CSS, dentro do body { }, adicione a linha de background:

body {
  font-family: Arial, sans-serif;
  font-size: 16px;
  background-color: #e0f2fe; ← adicione esta linha
}
🎨O azul clarinho #e0f2fe deixa a página com um visual mais suave. Tente outros valores: #f0fdf4 (verde claro) ou #fef3c7 (amarelo claro).
PASSO 4 — Estilizar o título

Deixar o h2 centralizado e bonito

Após o fechamento do body { }, adicione um novo seletor para o h2:

h2 {
  text-align: center;
  color: #1e3a5f;
  margin-bottom: 20px;
}
✅Título centralizado e com cor escura combinando com o fundo azul!
PASSO 5 — Estilizar os labels

Dar estilo aos rótulos dos campos

Adicione mais um seletor para o label:

label {
  display: block;
  font-weight: bold;
  color: #334155;
  margin-bottom: 4px;
}
⚠️display: block faz o label ocupar uma linha inteira, sem precisar do <br>! Mas no HTML mantemos o br por enquanto.
PASSO 6 — Estilizar os inputs

Campos com borda e espaçamento

Por último, dê estilo aos campos de texto:

input {
  width: 100%;
  padding: 8px 12px;
  border: 1px solid #94a3b8;
  border-radius: 6px;
  font-size: 15px;
  margin-bottom: 12px;
}
🎉Parabéns! O formulário agora tem cara de projeto de verdade! Compare com o início — que diferença!
