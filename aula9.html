Primeiros passos com JavaScript

submit, DOM, value e innerText

Fazer o formulario conversar com a pagina sem banco de dados ainda.

Ideia central

DOM
O JavaScript enxerga os elementos da pagina.
value
Pega o que foi digitado em um campo.
innerText
Escreve uma mensagem dentro de um elemento.

Exemplo minimo

<form id="formAluno">
  <input id="nome" placeholder="Seu nome">
  <button type="submit">Enviar</button>
</form>

<p id="resultado"></p>

<script>
const form = document.getElementById("formAluno");
const nome = document.getElementById("nome");
const resultado = document.getElementById("resultado");

form.addEventListener("submit", function(evento) {
  evento.preventDefault();
  resultado.innerText = "Aluno cadastrado: " + nome.value;
});
</script>

A mensagem vai aparecer aqui.

Resumo para o caderno

  • document.getElementById() encontra um elemento pelo id.
  • addEventListener("submit", ...) escuta o envio do formulario.
  • preventDefault() evita a pagina recarregar.
  • value pega o valor digitado; innerText mostra texto na tela.
