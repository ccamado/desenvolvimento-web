Checklist final do projeto

Corrigir pendencias, organizar evidencias e reforcar os erros mais comuns.

Checklist do aluno

☐ Minha pasta tem os arquivos com nomes simples: index.html, sobre.html, etc.
☐ Meu formulario tem campos basicos e campos de escolha.
☐ Meu CSS deixa os campos legiveis e organizados.
☐ Meus links funcionam entre as paginas.
☐ Minha tabela mostra dados em linhas e colunas.
☐ Meu JavaScript mostra pelo menos uma mensagem na pagina.

Erros comuns para revisar

Arquivo errado
sobre.html e diferente de Sobre.html.
Tag aberta
Conferir se toda tag importante foi fechada.
Radio sem grupo
Radios do mesmo grupo precisam do mesmo name.
JavaScript nao acha id
O id usado no JS deve existir no HTML.

Entrega final

Mostrar o projeto rodando no navegador e explicar, em poucas frases, o que cada parte faz: formulario, CSS, links, tabela e JavaScript.
