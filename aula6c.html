Lab 2: Criando um menu simples

Agora vamos melhorar as duas páginas criadas na aula anterior, colocando um menu igual nas duas páginas.

🎯 Resultado esperado

Ao final, o aluno terá duas páginas com um menu no topo: Home e Sobre.

HomeSobre

Página inicial

Exemplo de página com menu simples.

📋 Passos do Laboratório

PASSO 1

Adicionar o menu no index.html

Abra o arquivo index.html. Logo depois da abertura do <body>, coloque este menu:

<nav>
  <a href="index.html">Home</a>
  <a href="sobre.html">Sobre</a>
</nav>
A tag <nav> serve para agrupar links de navegação.
PASSO 2

Adicionar o mesmo menu no sobre.html

Agora abra o arquivo sobre.html e coloque o mesmo menu logo depois do <body>:

<nav>
  <a href="index.html">Home</a>
  <a href="sobre.html">Sobre</a>
</nav>
PASSO 3

Organizar o conteúdo da Home

Deixe sua página inicial com título, parágrafo e o formulário das aulas anteriores, se possível:

<h1>Página inicial</h1>
<p>Bem-vindo ao meu site de Desenvolvimento Web.</p>

<form>
  <label>Nome:</label><br>
  <input type="text" placeholder="Seu nome">
</form>
PASSO 4

Dar acabamento com CSS simples

Dentro do <head>, antes de fechar </head>, coloque:

<style>
  body {
    font-family: Arial, sans-serif;
    background-color: #f0f4ff;
    padding: 20px;
  }

  nav {
    background-color: #dbeafe;
    padding: 12px;
    border-radius: 8px;
    margin-bottom: 20px;
  }

  nav a {
    margin-right: 15px;
    text-decoration: none;
    font-weight: bold;
  }
</style>
Desafio: troque as cores do menu e do fundo sem apagar a estrutura.

📒 Resumo para copiar no caderno

✏️ Copie — Aula 6C

  • A tag <nav> é usada para agrupar links de navegação.
  • Um menu é um conjunto de links que ajuda o usuário a andar pelo site.
  • O mesmo menu pode aparecer em várias páginas do site.
  • Exemplo de menu: <nav><a href="index.html">Home</a></nav>.
  • O CSS pode melhorar o menu com fundo, espaçamento, borda e cores.
  • text-decoration: none; remove o sublinhado do link.
  • margin-right cria espaço entre um link e outro.
