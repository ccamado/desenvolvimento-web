Tipos de Input e Validação

Duração: 50 min  ·  Sala de aula  ·  Prof. Claudio Amado

🎯 Por que usar tipos diferentes?

Lembra que cada campo guarda um dado? O navegador precisa saber que tipo de dado esperar. Idade é número, e-mail tem @, senha deve ficar escondida. O atributo type faz essa mágica!

💡 Regra de ouro: Use o type certo → o celular mostra o teclado certo → o usuário erra menos!

📋 Os 4 tipos que você precisa saber

type="text"
Texto livre, qualquer coisa
Ex: Nome, Cidade
type="number"
Apenas números
Ex: Idade, Código
type="email"
Exige @ e domínio
Ex: joao@gmail.com
type="password"
Esconde o que digita (•••)
Ex: Senha de acesso

🛡️ Validação: required e placeholder

required = campo obrigatório. O formulário não envia se ficar vazio.

placeholder = texto de exemplo que some quando o usuário digita.

<label>Idade:</label>
<br>
<input 
  type="number"
  placeholder="Ex: 16"
  required
>

💻 Código completo com todos os tipos

<form>

  <label>Nome:</label><br>
  <input type="text" placeholder="Seu nome completo" required>
  <br><br>

  <label>Idade:</label><br>
  <input type="number" placeholder="Ex: 16" required>
  <br><br>

  <label>E-mail:</label><br>
  <input type="email" placeholder="voce@email.com" required>
  <br><br>

  <label>Senha:</label><br>

  <br><br>

  <button type="submit">Enviar</button>

</form>

📒 Resumo para o caderno

✏️ Copie no caderno — Aula 2

  • type="text" → texto livre (nome, cidade)
  • type="number" → somente números (idade, código)
  • type="email" → exige @ e domínio (.com, .br…)
  • type="password" → esconde o texto digitado (•••)
  • placeholder="texto" → dica dentro do campo (some ao digitar)
  • required → campo obrigatório; formulário não envia se vazio
  • Fórmula: <input type="TIPO" placeholder="DICA" required>
