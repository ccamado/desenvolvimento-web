Formulários HTML: o começo de tudo

Duração: 50 min  ·  Sala de aula  ·  Prof. Claudio Amado

💡 O que é um formulário?

Pensa assim: toda vez que você preenche uma ficha de cadastro, tá fazendo o que? Informando dados. Na web é exatamente igual. O formulário é a janela entre o usuário e o sistema.

🔑 Ideia principal: cada campo do formulário = uma informação (dado) que o usuário vai fornecer. Nome, turma, cidade — são dados!

🏗️ Estrutura mínima do Form

Veja as 3 tags que formam o esqueleto de qualquer formulário:

<!-- 1. <form> = a caixa que agrupa tudo -->
<form>

  <!-- 2. <label> = o nome do campo (o "título") -->
  <label>Seu Nome:</label>
  <br>

  <!-- 3. <input> = a caixinha onde o usuário digita -->
  <input type="text">
  <br><br>

</form>

O <br> pula linha — é o "enter" do HTML. Sem ele, tudo fica junto na mesma linha!

💻 Código completo da prática

Formulário com Nome, Turma e Cidade:

<form>

  <label>Nome:</label>
  <br>
  <input type="text">
  <br><br>

  <label>Turma:</label>
  <br>
  <input type="text">
  <br><br>

  <label>Cidade:</label>
  <br>
  <input type="text">
  <br><br>

  <button type="submit">Enviar</button>

</form>

📒 Resumo para o caderno

✏️ Copie no caderno — Aula 1

  • <form> — agrupa todos os campos do formulário
  • <label> — rótulo/título do campo
  • <input type="text"> — caixa de texto para digitar
  • <br> — pula linha (quebra de linha)
  • <button type="submit"> — botão de enviar
  • Fórmula: label + br + input + br = 1 campo
  • Formulário = conjunto de campos que coletam dados
