Links e Navegação: saindo de uma página para outra

Nesta aula, o aluno entende que um site pode ter várias páginas e que o link é o caminho entre elas.

🔗 O que é um link?

Um link é um elemento clicável que leva o usuário para outro lugar: outra página do mesmo site, outro site, um arquivo ou uma seção.

Ideia principal: link é caminho. Se o formulário é uma ficha, o link é a porta que leva para outra sala do site.

🏗️ A tag <a>

A tag usada para criar link é <a>. O endereço do destino fica no atributo href.

<a href="sobre.html">Ir para a página Sobre</a>
<a>
Cria o link.
href
Indica para onde o link vai.
Texto do link
É a parte que o usuário clica.

📌 Links internos e externos

Link interno leva para outra página do mesmo projeto. Exemplo: sobre.html.

Link externo leva para outro site. Exemplo: https://www.google.com.

<a href="index.html">Home</a>
<a href="https://www.google.com">Google</a>

📒 Resumo para copiar no caderno

✏️ Copie — Aula 6A

  • Um site pode ter uma ou várias páginas HTML.
  • Link é um caminho clicável que leva o usuário para outra página ou site.
  • A tag de link é <a>.
  • O atributo href indica o destino do link.
  • Exemplo: <a href="sobre.html">Sobre</a>.
  • Link interno aponta para arquivo do próprio projeto, como index.html.
  • Link externo aponta para outro site, começando geralmente com https://.

✅ Checagem rápida

1) Qual tag cria um link? Resposta: <a>
2) Qual atributo indica o destino do link? Resposta: href
3) Em <a href="sobre.html">Sobre</a>, qual é o texto clicável? Resposta: Sobre
