📋 Passos do Laboratório 2

PASSO 1 — HTML com classe

Estrutura HTML usando a classe "card"

No Lab 1 usamos tags soltas. Hoje vamos usar uma classe CSS — isso é muito mais poderoso! Cole no HTML:

<div class="card">

  <h2>📝 Ficha do Aluno</h2>

  <form>

    <label>Nome Completo:</label>
    <input type="text" placeholder="Seu nome" required>

    <label>Turma:</label>
    <input type="text" placeholder="Ex: 2A" required>

    <label>E-mail:</label>
    <input type="email" placeholder="voce@email.com" required>

    <button type="submit">Enviar Ficha →</button>

  </form>

</div>
💡Percebeu que não usamos mais <br>? O CSS vai cuidar dos espaçamentos!
PASSO 2 — Fundo da página

Centralizar e dar fundo gradiente

Na caixa CSS, comece com o body — vamos usar um gradiente de fundo e centralizar o card:

body {
  font-family: Arial, sans-serif;
  /* gradiente de fundo: 2 cores que misturam */
  background: linear-gradient(135deg, #e0f2fe, #ddd6fe);
  min-height: 100vh;
  /* estes 3 juntos = centralizar na tela */
  display: flex;
  align-items: center;
  justify-content: center;
}
🎨linear-gradient mistura duas cores criando um degradê. display: flex é o truque para centralizar o card na tela!
PASSO 3 — O card branco

Criar a "cartinha" com sombra

Adicione o seletor .card (com ponto = classe CSS):

.card {
  background: #ffffff;
  border-radius: 16px;
  padding: 32px;
  width: 100%;
  max-width: 400px;
  /* sombra: deslocX deslocY blur cor */
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.12);
}
✅Você deve ver um card branco centralizado na tela. Está tomando forma!
PASSO 4 — Título do card

Estilizar o h2 dentro do card

h2 {
  text-align: center;
  color: #1e3a5f;
  font-size: 1.3rem;
  margin-bottom: 24px;
}
PASSO 5 — Labels e Inputs

Campos com espaçamento perfeito

label {
  display: block;
  font-size: 0.85rem;
  font-weight: bold;
  color: #334155;
  margin-bottom: 4px;
  margin-top: 14px;
}

input {
  width: 100%;
  padding: 10px 14px;
  border: 2px solid #e2e8f0;
  border-radius: 8px;
  font-size: 0.95rem;
  color: #1e293b;
  /* box-sizing garante que width:100% não ultrapasse */
  box-sizing: border-box;
}
PASSO 6 — Botão com gradiente

O botão que vai impressionar!

button {
  width: 100%;
  margin-top: 20px;
  padding: 12px;
  background: linear-gradient(90deg, #3b82f6, #6366f1);
  color: #ffffff;
  border: none;
  border-radius: 10px;
  font-size: 1rem;
  font-weight: bold;
  cursor: pointer;
}
🎉Pronto! Compare com o início — você criou um formulário com visual profissional usando apenas CSS!
🚀
Desafio extra (se terminar antes): Adicione ao CSS do input: transition: border-color 0.2s; e depois crie input:focus { border-color: #3b82f6; outline: none; } — ao clicar no campo, a borda vai ficar azul!
