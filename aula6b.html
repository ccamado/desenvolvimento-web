Lab 1: Criando duas páginas HTML

Nesta prática, o aluno cria dois arquivos: index.html e sobre.html, e aprende a navegar de uma página para outra.

💻 Antes de começar

Use o jeito que funcionar melhor no laboratório:

Opção online: StackBlitz, PlayCode ou outro editor disponível.

Plano B offline: Bloco de Notas + navegador. Salvar arquivos na mesma pasta.

Importante: os arquivos index.html e sobre.html precisam ficar na mesma pasta.

📋 Passos do Laboratório

PASSO 1

Criar a pasta do projeto

Crie uma pasta chamada aula6-links. Dentro dela, teremos dois arquivos HTML.

PASSO 2

Criar o arquivo index.html

Copie este código para o arquivo index.html:

<!DOCTYPE html>
<html lang="pt-br">
<head>
  <meta charset="UTF-8">
  <title>Minha Home</title>
</head>
<body>
  <h1>Página inicial</h1>
  <p>Esta é a primeira página do meu site.</p>
  <a href="sobre.html">Ir para a página Sobre</a>
</body>
</html>
PASSO 3

Criar o arquivo sobre.html

Agora crie o segundo arquivo, chamado sobre.html:

<!DOCTYPE html>
<html lang="pt-br">
<head>
  <meta charset="UTF-8">
  <title>Sobre</title>
</head>
<body>
  <h1>Sobre mim</h1>
  <p>Meu nome é ________ e estou aprendendo HTML.</p>
  <a href="index.html">Voltar para a Home</a>
</body>
</html>
PASSO 4

Testar no navegador

Abra o index.html no navegador. Clique no link para ir para sobre.html. Depois clique no link de voltar.

Se o link não funcionar, confira se o nome do arquivo está exatamente igual: sobre.html, sem acento e sem espaço.

📒 Resumo para copiar no caderno

✏️ Copie — Aula 6B

  • Um site pode ser formado por vários arquivos HTML.
  • A página principal normalmente se chama index.html.
  • Para criar outra página, posso criar outro arquivo, como sobre.html.
  • Para ligar uma página na outra, uso a tag <a>.
  • O caminho do arquivo fica no atributo href.
  • Exemplo: <a href="sobre.html">Sobre</a>.
  • Arquivos ligados por link devem estar na mesma pasta ou com caminho correto.

✅ Entrega da aula

Ao final, o aluno deve ter dois arquivos funcionando: index.html indo para sobre.html, e sobre.html voltando para index.html.
