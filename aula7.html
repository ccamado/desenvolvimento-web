Semantica e Tabelas HTML

Organizar melhor a pagina e criar uma tabela para pre-visualizar os dados do formulario.

Objetivo da aula

Semantica
Usar tags que explicam a funcao de cada parte da pagina.
Tabela
Mostrar dados em linhas e colunas com table, tr, th e td.
Ponte com banco
Entender que cada campo do formulario pode virar uma coluna.

Tags semanticas essenciais

<header>Cabecalho da pagina</header>
<nav>Menu de navegacao</nav>
<main>Conteudo principal</main>
<section>Bloco de conteudo</section>
<footer>Rodape</footer>

Elas ajudam a deixar o projeto mais organizado e mais facil de entender.

Tabela HTML

<table>
  <tr>
    <th>Nome</th>
    <th>Turma</th>
    <th>Cidade</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>2A</td>
    <td>Campo Grande</td>
  </tr>
</table>
NomeTurmaCidade
Ana2ACampo Grande

Resumo para o caderno

  • Semantica e usar tags com significado: header, nav, main, section, footer.
  • Tabela organiza dados em linhas e colunas.
  • th e cabecalho; td e dado comum.
  • Campos do formulario podem virar colunas de uma tabela.

Entrega da aula

☐ Criar uma pagina com header, main e footer.
☐ Criar uma tabela com Nome, Turma e Cidade.
☐ Preencher pelo menos 3 linhas ficticias.
☐ Explicar no caderno a ligacao entre formulario, tabela e banco de dados.
