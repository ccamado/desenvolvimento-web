Campos de Escolha: radio, select e checkbox

Duração: 50 min  ·  Sala de aula  ·  Prof. Claudio Amado

🤔 Quando usar cada um?

Às vezes o usuário não precisa digitar — ele só precisa escolher. Isso evita erros e agiliza o preenchimento. Temos 3 tipos de campos de escolha:

🔘 radio
Escolha uma opção entre várias
Ex: Série (1º / 2º / 3º)
📋 select / option
Lista suspensa para escolha única
Ex: Cidade (lista de cidades)
☑️ checkbox
Marcar várias opções ao mesmo tempo
Ex: Interesses (Esporte, Música, Tech)
💡 Dica: radio = só 1 escolha | checkbox = pode marcar vários | select = lista compacta

🔘 Radio — escolha uma opção

O atributo name igual agrupa os radio buttons (garante que só um seja marcado).

<!-- Todos com o mesmo name="serie" -->
<p>Qual é sua série?</p>

<input type="radio" name="serie" value="1ano"> 1º Ano
<br>
<input type="radio" name="serie" value="2ano"> 2º Ano
<br>
<input type="radio" name="serie" value="3ano"> 3º Ano

📋 Select — lista suspensa

O <select> cria a caixinha e cada <option> é um item da lista.

<label>Cidade:</label>
<br>
<select name="cidade">
  <option value="">-- Selecione --</option>
  <option value="cg">Campo Grande</option>
  <option value="dou">Dourados</option>
  <option value="cor">Corumbá</option>
</select>

☑️ Checkbox — múltiplas escolhas

Diferente do radio, o checkbox permite marcar mais de um ao mesmo tempo.

<p>Seus interesses:</p>

<input type="checkbox" name="interesse" value="esporte"> Esporte
<br>
<input type="checkbox" name="interesse" value="musica"> Música
<br>
<input type="checkbox" name="interesse" value="tecnologia"> Tecnologia

👁️ Pré-visualização

1º Ano    2º Ano    3º Ano
Esporte    Música    Tecnologia

📒 Resumo para o caderno

✏️ Copie no caderno — Aula 3

  • radio → escolha única; todos com o mesmo name="grupo"
  • select/option → lista suspensa compacta; bom para muitas opções
  • checkbox → múltipla escolha; o usuário pode marcar vários
  • value="valor" → o dado que vai ser enviado ao sistema
  • radio e checkbox precisam de name igual para funcionar no grupo
  • select tem option filha (uma por linha de opção)
  • Regra: 1 opção obrigatória = radio | Várias = checkbox | Lista longa = select
